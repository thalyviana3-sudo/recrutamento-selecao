📊 Banco de Dados — People Analytics

Projeto desenvolvido para aplicar, na prática, conceitos de modelagem de dados voltados para a área de Recursos Humanos, integrando múltiplos subsistemas de RH em um banco de dados relacional centralizado.


🎯 Objetivo

Estruturar um banco de dados relacional completo para gerenciamento de processos de RH, abrangendo Recrutamento & Seleção, Departamento Pessoal, Treinamento & Desenvolvimento e Endomarketing — com boas práticas de modelagem, organização de dados e geração de indicadores de People Analytics.

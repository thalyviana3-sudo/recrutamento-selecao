# 📊 Banco de Dados — Recrutamento e Seleção

Projeto desenvolvido para aplicar, na prática, conceitos de **modelagem de dados** voltados para a área de Recrutamento e Seleção.

---

## 🎯 Objetivo

Estruturar um banco de dados relacional completo para gerenciar processos seletivos, candidatos, vagas, gestores e custos de recrutamento, utilizando boas práticas de modelagem e organização de dados.

---

## 🛠️ Ferramentas utilizadas

- **MySQL** — criação e gerenciamento do banco de dados
- **MySQL Workbench** — modelagem e execução de queries
- **Power BI** — dashboard com indicadores de People Analytics
- **Git & GitHub** — versionamento do projeto

---

## 🗂️ Estrutura do banco

O banco possui 9 tabelas relacionadas entre si:

| Tabela | Descrição |
|---|---|
| `candidato` | Dados pessoais e profissionais dos candidatos |
| `endereco_candidato` | Endereço vinculado ao candidato |
| `vaga` | Informações sobre as vagas abertas |
| `processo_seletivo` | Etapas e status de cada processo |
| `gestor` | Gestores responsáveis pelas vagas |
| `departamento` | Departamentos da empresa |
| `area` | Áreas de atuação |
| `pacote_beneficio` | Benefícios oferecidos por vaga |
| `custo_fonte_recrutamento` | Custos por canal de recrutamento |
